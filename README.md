# Netly Core

Sitio web de [Netly Core](https://netlycore.dev): páginas web para gimnasios y negocios en Quito.

- HTML, CSS y JavaScript sin frameworks (un solo archivo, carga rápida).
- Publicado en Netlify con el dominio `netlycore.dev`.

## Editar
- Número de WhatsApp: al final de `index.html`, constante `WHATSAPP`.
- Precios: sección `#planes` en `index.html`.
- Imágenes: carpeta `img/`.

## Publicar
Netlify publica automáticamente cada `git push` a `main` (después de conectar el repositorio en Netlify).
